# CS193-Project

**Problem Statement**: It is hard to keep track of my runs and progress running.  
  
**Solution**: A Java command line tool that keeps track of your runs in a file, including the information such as distance, time, pace, etc. It can then output you statistics as well as in a graph.  
  
**Eisenhower Matrix**:  
| | Urgent | Not Urgent |
| :--- | :--- | :--- |
| **Important** | **Do First**<br>- Record your data<br>- Save to file | **Schedule**<br>- View statistics<br>- View graphs |
| **Not Important** | **Delegate**<br>- Good formatting in command line<br>- Create test data | **Delete**<br>- Build a GUI<br>- Add database |
  
**Tech Stack**:  
Language: Java  
Libraries: JFreeChart  
Storing Data: CSV Files  

**Chunked Build Plan**:  
- Set up github repo and environment  
- Prompt the user for new run data  
- Save data in a csv file  
- Read from csv file  
- User can access information such as total miles ran, total time ran, average pace, etc  
- Create graphs of your progress
